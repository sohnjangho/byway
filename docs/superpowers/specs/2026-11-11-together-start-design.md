# 함께 달리기 다듬기 · 출발 화면 고르기 설계 (2026-11-11 밤)

브랜치 `feature/together-start` (`feature/more-courses` eb2e02d 위). PM 지시와 "진행" 승인(채팅).

## PM 지시
- 함께달리기: 각 기능별로 구획되지 않음. "파티"보다 "함께 달리기", "파티원"을 "함께 달릴 친구"로. 코스를 고르지 않았는데 이미 코스가 지정되어 있음.
- 출발을 누르면 "주행 화면을 셋으로 나눕니다"가 어떻게 구성되는지 모르겠음. 플레오스 화면을 예시로 간략하게 보여주고 3분할(차량정보+내비+에움길 또는 차량정보+에움길+내비)과 2분할(차량정보+내비) 중 고르게.

## 1. 함께 달리기
- 화면의 "파티" → "함께 달리기", "파티원"/"멤버" → "함께 달릴 친구". 위치 동의, 승낙 질문, 공유 범위, 주행 확대 지도 글, 서버 안내 문구까지. 메뉴 이름 "함께달리기"와 코드 이름(party)은 그대로(내 판단).
  - 기본 이름 "닉네임의 파티" → "닉네임와(과) 함께 달리기"는 받침에 따라 "과/와".
- 구획: 기능마다 테두리 있는 칸(bgRaised, RADIUS_MD, 안쪽 여백)에 제목을 달아 묶는다.
  - 밖: 내 프로필 / 함께 달릴 친구 초대 / 코드로 참여 / 즐겨찾는 함께 달리기
  - 안: 코드 / 코스 / 함께 달릴 친구 목록 / 버튼 줄은 칸 밖 아래
- 코스가 이미 정해져 있던 원인: 시연 모임에 지난 촬영 때 고른 코스가 남아 있었다. 한 번 고른 코스를 "다시 출발"용으로 계속 들고 있는 구조다.
  - 고침: 리더의 코스가 끝나면(끝까지 달림 또는 "코스 끝내기") 앱이 서버에 코스 비우기를 보낸다. 다음 코스는 리더가 다시 고른다.
  - 서버: `DELETE /v1/parties/{code}/course`(리더만, 아니면 403). 코스를 비우면 질문도 사라진다.
  - "다시 출발" 버튼을 없앤다.
  - 시연 모임을 새로 만든다.

## 2. 출발 화면 고르기
- "내비에 코스 입히기"를 누르면 출발 배치를 고르는 화면이 뜬다. 고르기 칸 세 개, 칸마다 플레오스 화면을 간략히 그린 그림(위 상태 막대, 아래 버튼 줄, 칸 나눔과 이름):
  1. 3분할: 차량 정보 + 내비 + 에움길
  2. 3분할: 차량 정보 + 에움길 + 내비
  3. 2분할: 차량 정보 + 내비
- 지난번 고른 배치가 미리 골라져 있다(설정 "주행 화면"과 같은 값, 설정도 세 가지).
- 출발 버튼 하나("이 화면으로 출발"). 누르면:
  - 3: 지금 2분할이면 바로 출발(내비가 앱 칸을 씀). 지금 1/3이면 "⋮을 오른쪽 끝까지 끌어 2분할로 돌아가면 출발합니다"를 보이고, 넓어지는 순간 출발.
  - 1·2: 지금 1/3이면 바로 출발. 아니면 "오른쪽 끝 ⋮을 왼쪽으로 끌어 셋으로 나누면 출발합니다"를 보이고, 나뉘는 순간 출발.
  - 1: 내비를 띄운다(3분할에서 새로 띄운 앱은 가운데, 에움길은 오른쪽 — 11-11 실측).
  - 2: 내비를 띄운 뒤 에움길을 다시 앞으로 불러 가운데로 온다(같은 규칙). 에뮬레이터에서 확인한다.
- "닫기"는 그대로.

## 하지 않을 것
- 앱이 화면을 직접 나누기(API 없음).
- 서버 자료 이름(party) 바꾸기.
