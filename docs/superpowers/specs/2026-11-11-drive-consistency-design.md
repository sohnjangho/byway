# 주행 화면을 홈과 같은 디자인으로 맞춤

- 날짜: 2026-11-11
- 바탕: PM 지적(11-11) "주행화면이랑 홈화면의 디자인 일관성이 없어". 비교 결과 6군데가 달랐고, PM은 "홈 기준으로 주행을 맞춤"을 골랐다.
- 기준 브랜치: `feature/design-polish` 13358b5. 작업 브랜치: `feature/drive-consistency`.

## 1. 무엇이 달랐나

일반 주행 화면은 이미 홈과 같은 지도 장면(`SceneView`)과 배경(`DriveBackdrop`)을 쓴다. 다른 곳은 아래와 같다.

| # | 홈 | 주행 |
|---|---|---|
| 1 지도 바탕 | 지형 지도(EOX) 위에 코스 | 파티 확대 지도(`CoursePathView.zoom`)는 지도 없이 흐린 사진 위에 선만 |
| 2 코스 선 | 빛 번짐 + 어두운 테두리 + 구간 색(`NightPalette.moodColor`) | 확대 지도는 테두리 + 낮 팔레트 구간 색(`palette.moodColor`), 더 어둡다 |
| 3 글 칸 바탕 | 2/3는 분위기 색 + 흐린 사진, 1/3은 색만 | 확대 중에는 사진을 화면 전체로 넓힘, 1/3에도 사진 |
| 4 출처 | 검은 둥근 칩 | 확대 지도는 칩 없이 회색 글자 |
| 5 코스 주변 목록 | "종류 · 설명 · 0.3km 지점" 한 줄 | 설명 줄과 오른쪽 거리 칸으로 나뉨 |
| 6 버튼 | 보조 버튼은 면(`bgRaised`)과 선 | "코스 끝내기"는 선만 있어 사진 위에서 잘 안 보임 |

## 2. 바꾸는 것

1. **확대 지도에 홈과 같은 지도를 깐다.** 설정 "지도 보기"를 따라 EOX Terrain Light 또는 Sentinel-2 cloudless 2016 조각을 실행 중에 받아 그린다. 앱에 든 장면 그림은 1442×726이라 5km 범위로 키우면 4~8배 흐려져 쓸 수 없다.
   - 밤 조각은 도구(`tools/make-covers.py`의 `night_map`, `darkened`)와 같은 변환을 한다. 위성의 대비 기준값은 조각마다 달라 이음매가 생기지 않도록 장면 15개 평균인 45로 고정한다.
   - 불투명도(낮 0.86, 밤 0.66), 글 칸 아래 16%, 짙어지는 띠는 장면과 같다(`sceneFadeOnScreen`).
   - 투영은 조각과 맞도록 웹 메르카토르로 한다. 멤버를 맞추는 범위는 글 칸 옆 지도 자리(2/3)나 지도 칸 전체(1/3)이고, 지도 조각은 글 칸 아래까지 깔린다.
   - 받지 못하면(터널, 오프라인) 지금처럼 분위기 색 위에 코스 선과 핀만 그린다. 조각은 기기 캐시에 두고, 도착하면 그 자리에 나타난다(움직임 효과 없음).
2. **코스 선, 번호, 위치 표시를 장면과 같이 그린다.** 선은 장면과 같은 세 겹과 같은 굵기다. 코스 주변 장소의 번호 원과 주황 위치 점(흰 테두리, 옅은 후광)도 장면과 같다. 그리는 함수는 장면과 함께 쓴다.
3. **출처는 장면의 칩을 그대로 쓴다.** 확대 중에는 장면의 지도만 숨기고 칩은 남긴다. 확대 지도 안의 출처 글자는 없앤다.
4. **글 칸 바탕은 홈과 같다.** 확대 중에도 사진을 화면 전체로 넓히지 않는다. 1/3 칸은 홈처럼 색만 깐다(사진 출처 줄도 없어진다).
5. **코스 주변 목록은 홈 형식이다.** 이름 아래 "종류 · 설명 · 2.0km 앞" 한 줄이고 오른쪽 거리 칸은 없앤다.
6. **"코스 끝내기"는 홈의 보조 버튼과 같은 면과 선을 쓴다.** 주행 규칙대로 눌림 움직임은 없다. 같은 버튼을 쓰는 기록 중 화면도 같이 바뀐다.

## 3. 그대로 두는 것

- 큰 남은 거리 숫자, 메뉴 없음, 움직이는 것은 위치 점뿐(주행 규칙).
- 확대 지도에만 있는 정보: 축척, 핀 아래 닉네임, 먼 멤버 수.
- 일반 주행의 지도 장면(이미 홈과 같다).

## 4. 제약

- 지도 조각은 키 없는 EOX 공개 타일이다. 이미 쓰는 출처와 같은 층이라 출처 문구는 그대로다(`docs/권리점검.md` 14·15행).
- 요청 머리말은 일반 이름(`byway-app`)을 쓴다. 개인 정보를 싣지 않는다.
- 줌은 10~15로 묶는다. 한 번에 받는 조각은 화면을 덮는 만큼이다(2/3 칸 약 35장).
- `ai.pleos.*`는 `platform/`에만 둔다(이번 변경은 해당 없음).
